# Ball Up / 球球碰碰

一个适合浏览器和后续微信小游戏改造的本地合成游戏原型。当前版本采用球球碰碰视觉系统：米灰与橄榄绿配色、紧凑棋盘、成长图鉴、皮肤编辑器和本地音效引擎。

## 本地运行

这是一个无构建步骤的静态网页。进入项目目录后运行：

```bash
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

## 当前玩法

- 经典、60 秒挑战、轻松模式
- Matter.js 重力、碰撞、合成与危险线
- Combo、粒子效果、音效和最高分
- 10 级成长图鉴与下一只预览
- 本地图片换肤、批量图片导入和自定义名称
- 本地预设、每日任务和一次复活

图片和游戏进度保存在当前浏览器中。音频示例以内置数据形式随项目提供，后续可替换为微信小游戏的音频资源管理方式。
